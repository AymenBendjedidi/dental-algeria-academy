# Dental Algeria Academy

A complete educational website for dental students in Algeria, designed as a professional learning platform.

## Overview
This project includes:
- Homepage and landing sections
- Course catalog for dental education
- Resource library pages
- Quiz system for revision and score tracking
- Student dashboard UI
- Responsive design for mobile and desktop
- Theme switcher and local login mock flow

## Tech used
- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage for student session persistence

## Run locally
Open the project folder and start a local static server, for example:

```bash
python3 -m http.server 8000
```
Then open:

```text
http://localhost:8000/
```

## Project structure
- `index.html` — homepage
- `courses.html` — course catalog
- `resources.html` — educational resources
- `quiz.html` — quiz page
- `dashboard.html` — student dashboard
- `styles.css` — full styling
- `app.js` — interactivity and quiz logic

## Notes
This is a polished frontend prototype tailored to Algerian dental students with content focused on local academic needs and best practices for educational platforms.
